STOCKAGE DES FACTURES ET BL — CLOUDFLARE R2 (gratuit jusqu'à 10 Go)
====================================================================

1) Créer le bucket
   - dash.cloudflare.com → R2 Object Storage → activer R2 (gratuit ; une carte peut être demandée,
     rien n'est facturé sous 10 Go / mois).
   - « Create bucket » → nom : cami-documents → laisser PRIVÉ (ne pas activer l'accès public).

2) Créer une clé d'accès
   - R2 → « Manage R2 API Tokens » → « Create API token »
   - Permission : « Object Read & Write », limité au bucket cami-documents.
   - Noter : Access Key ID, Secret Access Key, et l'Account ID (visible sur la page R2).
   - Pas besoin de configurer CORS : les fichiers passent par votre serveur.

3) Ajouter dans backend/.env
   R2_ACCOUNT_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   R2_ACCESS_KEY_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   R2_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   R2_BUCKET=cami-documents

   Si le backend est hébergé (Render, VPS…), ajoutez ces 4 variables dans son panneau « Environment ».

4) Installer et redémarrer
   cd backend
   npm install            (installe @aws-sdk/client-s3 et @aws-sdk/s3-request-presigner — Node 18 minimum)
   puis redémarrer le serveur.

Rangement dans le bucket : achats/<année>/<n° BC>/facture-<n° BL>-….pdf  et  bl-<n° BL>-….jpg
Sans ces variables, l'application fonctionne normalement ; la fenêtre Documents affiche
« Stockage des documents non configuré ».
